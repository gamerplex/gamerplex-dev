# Platformer Design — Level Design, Difficulty, Teaching

## Level Design Principles

### The First Screen Teaches
Level 1-1 must teach movement, jumping, and the core mechanic without any text. Place:
- A safe flat area to learn movement
- A low platform that requires jumping
- A collectible that rewards jumping
- An enemy that can only be avoided by jumping
- A gap that proves falling is dangerous

### The Vocabulary of Danger
Establish visual rules and never break them:
- Spikes = instant death (red/sharp)
- Gaps = falling death (visible bottom or void)
- Enemies = damage (moving, colored, animated)
- Lava/water = instant death (animated surface)

### Difficulty Staircase
Each challenge should:
1. Introduce ONE new element
2. Let the player practice it safely
3. Combine it with a previous element
4. Increase speed/precision gradually

Never introduce two new things simultaneously.

### Checkpoint Placement
Place checkpoints:
- Before every difficulty spike
- After every new mechanic introduction
- Every 30-60 seconds of gameplay
- Before boss encounters

### Secret Areas
Hide rewards for exploration:
- Behind destructible walls (visual hint: slightly different color)
- Above the visible screen (reward jumping beyond the path)
- Behind fake walls (1 per level maximum, teach it early)

## Gamerplex Fit
- Score = coins + time bonus → Flipcash token
- SOAR leaderboard: fastest completion time
- Challenge link: "Beat my time on World 1-3"
- 1v1 speedruns via Contention Markets
